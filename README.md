# vim-escape-room

cinco puertas. una salida. un escape room que se juega dentro de vim.

### cómo jugar

```bash
git clone https://github.com/iriidian77/vim-escape-room.git
cd vim-escape-room
vim escape.txt
```

todo lo que necesitas está escrito dentro del archivo. cuando creas que saliste:

```bash
bash check.sh
```

### jugar otra vez

```bash
git restore escape.txt
```

### no tengo vim

- ubuntu / debian → `sudo apt install vim`
- fedora / alma → `sudo dnf install vim`
- macos → ya viene instalado
- windows → instala WSL y usa el comando de ubuntu
